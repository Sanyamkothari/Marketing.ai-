# Real-data catalogue

Every open dataset gathered to test Autonomy, 20 Oct 2026. The data lives in
`/home/user/datasets/<name>/` (never in the repo); each folder has a `SOURCE.txt` with the URL,
the licence where one is stated, the download time, the byte size and the SHA-256.

**Where the numbers come from.** Rows, customers and time spans were counted by
`scripts/v2_realdata/profile_datasets.py` (pandas, chunked for the big files), run as:

```bash
python3 -I scripts/v2_realdata/profile_datasets.py --out /home/user/datasets/_profile/profile_big.json \
    --only criteo_uplift,x5_retailhero,megafon,lenta,retailrocket
python3 -I scripts/v2_realdata/profile_datasets.py --out /home/user/datasets/_profile/profile_small.json \
    --only hillstrom,starbucks_promo,starbucks_rewards,open_bandit_sample,olist,online_retail_i,online_retail_ii,cdnow,ta_feng,dunnhumby_nbr,instacart_nbr,superstore,rees46_sample,taobao_sample,telco_churn,bank_marketing,health_insurance_xsell,hotel_bookings,uci_credit_default,kdd98_sample
```

The JSON outputs sit next to the data in `/home/user/datasets/_profile/`. Python 3.13 was used
because the system's 3.11 has no numpy or pandas; the script is 3.11-compatible. The heaviest job,
X5's 45.8M purchase lines, took 106 s with a peak RSS of 1.1 GB. Total on disk: 1.8 GB, well under
the 8 GB budget.

"Customers" means distinct person ids. Where a file has no id, one row is one person (the RCT files)
or the count is unknown ("no id").

## Notes for the next steps

- The two loaders in `autonomy/data/loaders.py` cover only Online Retail I and Hillstrom (and
  Hillstrom only with an added `customer_id` column). Every other dataset needs an adapter; see
  `INPUTS.md` section 10 for what a customer could not do without code.
- Only the A-family files support causal claims about targeting. On B, C and D, a run can show
  that the software reads the data, what state it builds and how fast, but not that the agent's
  choices would make money.
- X5 is the best real end-to-end case: a real randomised campaign (`uplift_train`) plus real
  pre-campaign receipts for the same 400k clients, at 45.8M lines.
