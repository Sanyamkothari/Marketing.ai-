# 02 — What "ready for AutoML" means here (Explore report, 12 Oct 2026; read-only)

SUMMARY: readiness = a set of contracts: training gate validate_for_training (19 codes + ext) at POST /runs → 409 VALIDATION_FAILED; uplift gate run_uplift_checks (7) at POST /uplift/runs; scoring gate validate_against_schema (after recipe replay); measurement contracts (outcomes, assignment, contact files). MAIN FINDING: passing validation ≠ run finishes: several conditions pass the validator then fail at split/train as plain ValueError → engine/errors.py:120-133 run_error → generic STAGE_FAILED (§1.7). Existing dry run: POST /uploads/{id}/checks → engine/agent/checks.py:20 check_plan (same code POST /runs runs). Readiness report should build on check_plan + run_uplift_checks + agent-only probes.

## Gates
Upload: engine/stages/ingest.py refuses unreadable files; intake (engine/intake/run.py) converts xlsx→CSV. Train generic: POST /runs → validate.validate_for_training (api/routes/runs.py:458-466), 409 with report (:515, body :868-880); pipeline repeats (engine/pipeline.py:798-819) RUN_BLOCKED_BY_VALIDATION. Uplift: POST /runs refuses UPLIFT_REQUIRES_UPLIFT_ROUTE (runs.py:790-806); POST /uplift/runs Phase 1 + uplift checks (api/routes/uplift.py:306,315; codes :408,:417; flow.py:466-498). Score: resolve version → refuse_other_roles → replay_for_scoring (RECIPE_* 409) → validate_against_schema (runs.py:468-506; pipeline :1441-1482). UPLOAD_MODE_MISMATCH (runs.py:441-446). passed = error_count==0 excluding acknowledged (validate.py:2054-2088); ack only on acknowledgeable findings (:2046), matched CODE or CODE:column via validation.acknowledged. Sampling: profile_row_cap 2,000,000 (ingest.py:118); PK_NOT_UNIQUE on capped read only details.sampled (validate.py:926-928) — duplicates beyond cap unseen.

## 4 Failure modes → AUTO / ASK / APPROVE
1 SUPPRESSION_COLUMN_MISSING → ASK map DND/opt-in; APPROVE negation or switch off (config-only, can't remap per run). 2 PK_NOT_UNIQUE → AUTO if reshape level + date (combine_rows point-in-time); else ASK grain. 3 TARGET_MISSING/NOT_BINARY/CONSTANT → ASK synonym/positive value; outcome from events ASK (Doctor sentence); numeric → ASK regression. 4 TOO_FEW_POSITIVES/ROWS_TOO_FEW → not fixable; ASK more data; lowering thresholds = APPROVE. 5 LEAKAGE_SUSPECTED → ASK hide or keep (keep = APPROVE). 6 time unparseable/split fail → AUTO parse_date when order proven; ASK when ambiguous; AUTO random_stratified when no date; guarantee 100% non-null + enough distinct dates. 7 numbers as text → AUTO parse_number (sure ≥95%); ASK ambiguous decimal mark. 8 placeholders 99/-1/9999 → ASK (set_missing never auto). 9 PK_NULLS → ASK. 10 high-null/constant/id-like/PII → AUTO report; keep PII = APPROVE. 11 consent vocabulary not truthy → ASK+APPROVE. 12 CONSENT_COLUMN_MISSING → APPROVE. 13 SCHEMA_MISMATCH/RECIPE_* at scoring → AUTO proven renames else ASK; type move needs re-export/retrain. 14 TREATMENT_NOT_BINARY → AUTO map_boolean; ASK control value; blanks ASK. 15 TREATMENT_NOT_RANDOM → APPROVE (not causal). 16 arm too small / feature after treatment → ASK more/earlier data. 17 outcomes not matured / invalid → AUTO keep key+outcome(+date); ASK positive_label; maturity = wait. 18 silent line drops, uniqueness beyond cap, immature labels, text regression target → AUTO detection, report.
Always APPROVE: ack of error-severity findings (leakage AUC, TREATMENT_NOT_RANDOM), governance/suppression changes (consent column, suppression switches, pii_handling keep), changing validation.min_* or leakage_check, model promotion.
