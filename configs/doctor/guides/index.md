# Guide index (read first when unsure)

- explore: read at first look or when a table surprises.
- cleaning_and_formats: read when text should be number, date, yes/no or ID.
- consent_and_privacy: read when a column is consent, personal or sensitive.
- grain_and_aggregation: read before summing, counting or grouping per customer.
- keys_and_joins: read when tables meet or an ID is in doubt.
- outcomes: read before defining or checking the target.
- returns_duplicates_guests: read when negatives, `C` invoices, repeats or blank IDs.
- sql_steps: read before `propose_sql`.
- time_and_as_of: read when dates or the as-of matter.
- features: read before proposing features.
- talking_to_the_person: read before asking, planning, finishing.

Hard rules: the person approves every change; minimum rows and positives stay; no post-as-of data in features.
Consent is never assumed; never repeat personal data.
Call only listed tools; else use the nearest look tool, saying what was unchecked.
