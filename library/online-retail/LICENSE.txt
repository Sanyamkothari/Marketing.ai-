WHICH ONLINE RETAIL THIS IS
---------------------------
This is **Online Retail**, the 2010-2011 log (541,909 lines), not **Online Retail II**, the
2009-2011 log (1,067,371 lines). Online Retail II is published as an .xlsx on the same UCI host,
which is unreachable from the environment this library was built in. The two have the same shape
and the same aggregation story; only the date range differs. See README.md.
